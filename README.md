# Snake-Eye Trainer

Duel Links Snake-Eye (Kurikara) study app: duel logs, deck list, scenario trainer, line sequencer and quiz. Works offline once opened.

## Put it on your phone
1. Create a GitHub repo and upload every file in this folder to its root.
2. Repo Settings > Pages > deploy from the main branch (root).
3. Open the Pages link on your phone, then Add to Home Screen.

Edit `data.js` for the duel logs and the lists at the top of `app.js` for the deck, scenarios and quiz facts.
