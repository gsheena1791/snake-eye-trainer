Install on your phone

  1. Publish these files to an HTTPS static host (GitHub Pages or Netlify).
  2. Open the published URL in Safari or Chrome.
  3. iPhone: Share → Add to Home Screen. Android: browser menu → Install app.

This ZIP is the app package, not a public URL. Updating is done by replacing the hosted files with a newer release at the same URL.
